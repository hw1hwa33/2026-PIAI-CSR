# 07_DESIGN_ANTIPATTERNS

## 목적

생성형 웹 디자인에서 자주 발생하는
과장, 가짜 인터랙션, 정보 위계 붕괴를 방지한다.

---

## Hard Prohibitions

### 1. 목적 없는 화려함

금지:
- Glow 남발
- Glassmorphism 남발
- 무의미한 Gradient
- Particle 장식
- 과도한 3D 효과
- 반복 Zoom
- 이유 없는 Floating

---

### 2. 모든 것을 Card로 만들기

모든 문단과 요소를 Rounded Card에 넣지 않는다.

Card는 독립적인 정보 단위에만 사용한다.

---

### 3. Fake UI

금지:
- 작동하지 않는 버튼
- 검색되지 않는 검색창
- 상태 없는 토글
- 변화 없는 필터
- 클릭되지 않는 카드형 컨트롤

---

### 4. Fake Data

실제 데이터 기반 자료에서 임의 수치를 만들지 않는다.

데이터가 없으면:
- No Data
- Placeholder
- Mock Data 표시

중 하나를 사용한다.

---

### 5. 의미 없는 Animation

금지:
- 모든 텍스트 Bounce
- 카드 무한 부유
- hover 360도 회전
- 모든 섹션 강제 Zoom
- 이유 없는 Auto-play

---

### 6. React 과설계

정적 보고서에 React를 강제하지 않는다.

기술 복잡성은 요구사항보다 높아서는 안 된다.

---

### 7. Desktop 축소형 Mobile

PC 레이아웃을 단순 축소하지 않는다.

모바일은 필요하면 구조를 재설계한다.

---

### 8. Hover 의존

핵심 정보와 기능을 Hover에만 숨기지 않는다.

---

### 9. Scroll Hijacking

기본 스크롤을 빼앗지 않는다.

---

### 10. Modal 남발

상세 설명까지 모두 Modal로 띄우지 않는다.

---

### 11. Chart Decoration

질문에 답하지 않는 차트를 넣지 않는다.

데이터가 있다는 이유만으로 차트를 만들지 않는다.

---

### 12. Pie Chart 남용

범주가 많거나 비교가 중요한 경우
Bar / Dot / Table 등을 우선 검토한다.

---

### 13. 색만으로 상태 전달

색 + 텍스트 + 아이콘 등 복수 신호를 사용한다.

---

### 14. 과도한 Radius

모든 요소를 pill 또는 rounded-3xl로 만들지 않는다.

---

### 15. Icon-only 남발

의미가 불명확한 아이콘에는 레이블을 제공한다.

---

### 16. 접근성 제거

outline을 없애고 대체 Focus를 제공하지 않는 행위를 금지한다.

---

### 17. 성능 희생

금지:
- 초대형 이미지
- 불필요한 4K Video
- 과도한 Blur
- 수백 개 DOM Animation
- 매 Scroll마다 무거운 계산
- 목적 없는 WebGL

---

## Final Antipattern Test

다음 질문에 YES면 수정한다.

- 예쁘기 위해 정보가 희생되었는가?
- 사용자가 무엇을 눌러야 하는지 헷갈리는가?
- 애니메이션이 의미 없이 시선을 빼앗는가?
- 모바일에서 구조가 무너지는가?
- 실제 동작하지 않는 UI가 있는가?
- 기술이 목적보다 앞서는가?
